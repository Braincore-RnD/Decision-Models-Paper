\section{Experimental Setup}
\subsection{Protocol}
Ten training runs (3 seeds of the base recipe, 2 LOTO, 2 ablations, LFM2-700M,
SmolLM2-360M, ModernBERT-base) on NVIDIA
T4 via Kaggle/Colab: AdamW, backbone LR $2\times10^{-4}$, head LR
$1\times10^{-4}$, cosine decay, effective batch 32, 3 epochs keeping best
eval-loss (per-run epoch losses in Table~\ref{tab:overfit}). Evaluation uses identical test sets everywhere
(BANKING77/CLINC150 500 items, typed-decisions 400): canonical accuracy plus a
paraphrase grid (canonical plus 2 wording/order variants; typed is not
paraphrased---its records carry fixed 5-question typed schemas, so the grid
applies to intent benches only), bootstrap
95\% intervals (2\,000 resamples on the A-LOTO, E-full, cal-1k, and SmolLM2
dumps; lean evals report point
estimates), measured per-item latency on T4,
and per-item probability dumps scored
with Brier, NLL, 10-bin ECE, error-detection AUROC, and coverage at 5\% risk.
The loss-curve figure (Figure~\ref{fig:loss}) replaces the earlier
pseudocode listing: epoch-1--3 eval-loss trajectories are the protocol's
fingerprint, so the figure \emph{is} the method summary.

Vendor numbers (Unsloth Qwen, Cloudflare Clef) are cited as labeled context,
never as rerun baselines; the size-matched reference is d1-omni-600M from the
same LFM lineage~\cite{liquid-d1}. The honest zero-shot floor is a baseline we
run ourselves: cosine similarity between utterances and label names with
\texttt{BAAI/bge-small-en-v1.5}~\cite{bge-small} on CPU (no training, no
label descriptions), on same-seed 500-subsets and full tests. Every run archives adapters, head, merged
weights, and \texttt{run\_meta.json} in its kernel output; lightweight results
(\texttt{eval\_results.json}, probability dumps, metric tables) are versioned
in \texttt{docs/eval/} of the public repo
(\url{https://github.com/Braincore-RnD/Decision-Models-Paper}).
